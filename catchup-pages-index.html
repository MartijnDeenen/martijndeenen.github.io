What Catch-up does

Catch-up is a personal, single-user tool. It checks a person's own Gmail, Google Drive, Google Calendar and Dropbox for new messages, files and events, and lets them ask a local AI model questions like "what's new since yesterday?" — entirely on their own computer.

Read-only, always.

It never sends, replies, deletes or changes anything in any connected account. It only reads what has changed.

Local-only.

Everything it fetches is stored on that one Mac. There is no server, no company, and no other user — it is not a public product, just one person's own tool.

Privacy policy

Last updated November 2026.

Catch-up is a single-user, personal application. It is not distributed, not offered as a service, and has exactly one user: the person who set it up on their own computer.

What it accesses

  • Gmail — read-only, to show new messages (gmail.readonly)
  • Google Drive — read-only file metadata, in folders the user chooses (drive.metadata.readonly)
  • Google Calendar — read-only, to show upcoming events (calendar.readonly)
  • Dropbox — read-only file metadata, in folders the user chooses

Where the data goes

All data stays on the user's own computer, in a local database. Nothing is sent to any third party, any analytics service, or any server operated by anyone other than the user themself. The only outbound calls are the read-only API requests above, made directly from the user's computer to Google and Dropbox, and requests to a locally-running AI model on the same machine.

Data retention and deletion

The user controls their own data entirely. They can disconnect any account at any time from the app's own settings, which also revokes Catch-up's access token, and can delete the local database file at any time to remove everything it has stored.

Contact

This application has a single developer and user. Questions about this policy can be sent to the developer via their GitHub profile.
